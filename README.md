# SubTrack (サブスク管理 & 家計簿連携ツール)

マネーフォワード ME などの家計簿アプリと連携し、固定費・サブスクリプションの集計、更新日前の解約防止アラート、不要サブスクの断捨離シミュレーションを行うWebアプリケーションです。

---

## 🌟 主な機能

### 1. 家計簿連携 (マネーフォワード ME)
- **明細CSVインポート**: マネーフォワード ME からダウンロードした「収入・支出詳細」CSVをドラッグ＆ドロップ（Shift_JIS / UTF-8 自動判別）。
- **定期課金・サブスク自動検知エンジン**:
  - 毎月の定期引き落とし（Netflix, Spotify, ChatGPT, Apple, 通信費, ジムなど）を自動検知。
  - 出現回数・直近間隔・既知サービス辞書から、次回推定請求日や推奨カテゴリを算出して一括登録。
- **デモデータ機能**: 手元にCSVがなくても「サンプルCSVで試す」ボタンで1タップ動作体験。

### 2. コスト集計 & 可視化
- **月額・年額相互自動換算**: 年払い（Amazon Prime等）や四半期払いを自動で月額換算。
- **年間総支出予測**: 今の契約を1年間続けた場合の総コストを即座に把握。
- **カテゴリ別支出割合**: 動画配信、AI・クラウド、通信、ジムなどの支出バランスをグラフィカルに表示。

### 3. 更新日前アラート & 解約防止
- **カウントダウン表示**: 次回請求日までの残り日数をリアルタイム表示（「本日更新！」「あと3日」等）。
- **解約直通リンク**: 各カードに公式解約ページへのリンクと、解約時の注意事項（「Webブラウザから解約が必要」など）を登録可能。
- **カレンダー連携**:
  - **iCalendar (.ics)**: iPhone、Mac、Outlookのカレンダーに一括登録（更新3日前にアラーム通知）。
  - **Google カレンダー**: ワンクリックで個別予定追加。

### 4. 不要サブスク断捨離シミュレーター
- **無駄サブスクあぶり出し**: 満足度（★1〜5）× 利用頻度（毎日〜ほぼ未使用）から、コストパフォーマンスの悪いサブスクを自動判定。
- **節約シミュレーション**: 解約した場合に浮く固定費（「年間 ¥○○ 節約」）を試算。
- **ワンタップ解約完了記録**: 解約達成時に confetti（紙吹雪）でお祝いし、年間削減実績をリアルタイム反映。

### 5. データ永続化 & バックアップ
- **完全ローカル保存**: すべてのデータはブラウザの `localStorage` に保存され、外部サーバーへ個人情報が送信されることはありません。
- **JSONバックアップ & 復元**: いつでもバックアップ保存・復元が可能。
- **CSVエクスポート**: 表計算ソフト（Excel、Googleスプレッドシート）用のCSV書き出しに対応。

## 🚀 起動方法

```bash
# 依存関係インストール (初回のみ)
npm install

# 開発サーバー起動
npm run dev

# プロダクションビルド
npm run build
```

ブラウザで `http://localhost:5173/` (または表示されたポート) を開きます。
